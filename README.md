# Mi Ciudad Colón

Guía turística de Colón (Entre Ríos) para el celular. Trabajo Final Integrador 2026 de Desarrollo para Móviles (UNER).

| Carpeta | Qué es |
|---|---|
| `MiCiudad/` | La app (Expo SDK 57) |
| `api-mi-ciudad/` | La API de la cátedra (NestJS) |
| `playbook/` | Menú para levantar todo en Windows o Linux |
| `docs/` | Documentación: arquitectura, recorridos de punta a punta y pruebas |

## Empezar

Con Node 24 instalado, desde esta carpeta:

```bash
node playbook/playbook.ts
```

Primero **Revisar mi compu** y **Preparar el proyecto**; después, todos los días, **Levantar todo y abrir la app**. La opción **Ver la documentación** abre todo en el navegador, en castellano o inglés.

*English: run `node playbook/playbook.ts` and pick "Ver la documentación" to read the docs in English.*
